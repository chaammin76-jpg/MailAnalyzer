# MailAnalyzer — Test Cases

## 1. Назначение

Документ содержит набор тест-кейсов для проверки основных функций приложения MailAnalyzer.

Тестирование выполняется вручную в пользовательском интерфейсе приложения.

---

## 2. Тестовые сценарии

|  ID   |              Функция            |              Входные данные / действие                 |                        Ожидаемый результат                      |
|-------|---------------------------------|--------------------------------------------------------|-----------------------------------------------------------------|
| TC-01 | Ручной ввод					  | Ввести текст с несколькими e-mail адресами			   | Адреса обнаружены и отображены в таблице						 |
| TC-02 | Подсчёт найденных адресов		  | Ввести текст с повторяющимися адресами				   | Счётчик «Всего найдено» учитывает все вхождения				 |

| TC-04 | Уникальность без учёта регистра | `Test@mail.ru`, `test@mail.ru`, `TEST@mail.ru`		   | При выключенном учёте регистра адрес считается одним уникальным |
| TC-05 | Уникальность с учётом регистра  | Те же адреса при включённом учёте регистра			   | Адреса с различным регистром считаются разными					 |

| TC-11 | Копирование					  | Выбрать одну или несколько строк и нажать «Копировать» | Выбранные адреса помещаются в буфер обмена						 |
| TC-12 | Экспорт TXT					  | Выполнить анализ и выбрать «Экспорт TXT»			   | Создаётся TXT-файл с результатами								 |
| TC-13 | Экспорт CSV					  | Выполнить анализ и выбрать «Экспорт CSV»			   | Создаётся CSV-файл с результатами								 |
| TC-14 | Почтовый клиент				  | Выбрать один или несколько адресов					   | Открывается почтовый клиент с выбранными адресами				 |
| TC-15 | Тема и текст письма			  | Заполнить тему и текст перед открытием клиента		   | Тема и текст передаются в почтовый клиент						 |
| TC-16 | История						  | Выполнить анализ и открыть историю					   | Выполненный анализ появляется в истории						 |
| TC-17 | Очистка истории				  | Открыть историю и подтвердить очистку				   | Записи истории удаляются										 |
| TC-18 | Настройки						  | Изменить параметры и сохранить						   | Изменённые параметры сохраняются								 |
| TC-19 | Сохранение настроек			  | Перезапустить приложение						       | Сохранённые настройки восстанавливаются						 |
| TC-20 | Путь сохранения				  | Указать существующую папку в настройках				   | Диалог сохранения открывается в указанной папке				 |
| TC-21 | Пустой ввод					  | Нажать «Анализировать» при пустом поле				   | Отображается предупреждение									 |
| TC-22 | Нет e-mail					  | Выполнить анализ текста без e-mail					   | Приложение не завершается с ошибкой							 |
| TC-23 | Экспорт без результатов	      | Нажать экспорт при отсутствии результатов			   | Отображается предупреждение									 |
| TC-24 | Копирование без выбора		  | Не выбирать строки и нажать «Копировать»			   | Отображается предупреждение									 |
| TC-25 | Почтовый клиент без выбора      | Не выбирать строки и нажать кнопку почтового клиента   | Отображается предупреждение									 |
